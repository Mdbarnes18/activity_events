jQuery Selectors Used

#changeButton
The ID selector targets the button with the ID "changeButton". It allows jQuery to attach a click event to that specific button.
#buttonResult
The ID selector targets the paragraph with the ID "buttonResult". jQuery uses it to change the text after the button is clicked.
#interactiveParagraph
The ID selector targets the paragraph with the ID "interactiveParagraph". jQuery uses it to respond when the paragraph is double-clicked.
#interactiveImage
The ID selector targets the image with the ID "interactiveImage". jQuery uses it to respond when the mouse moves over the image.
#imageResult
The ID selector targets the paragraph with the ID "imageResult" so jQuery can update its text when the image interaction occurs.
